Overview

The automation follows the message, not a complicated dashboard.

The product is organized around the real sequence from notification to reply. The controls stay visible in the Android app.

Reads the DM notification

The Notification Listener receives supported Instagram notifications and extracts the information needed by the reply engine.

Matches your rule

Rules can use text matching, specific contacts, group-chat behavior, ignored contacts, delays and daily limits.

Generates the response

The selected AI provider receives the configured prompt and message context and returns reply text.

Sends the reply

The app uses the notification reply action where available, with the project's accessibility fallback when needed.

Keeps the history

Reply activity is stored locally so you can review what happened from the dashboard and history screens.

No login required

Operates from Android notification access. It never asks for an Instagram username or password.

FAQ

Questions, answered plainly.

Does InstaReply Bot need my Instagram password?
No. The app works from Android Notification Access on supported Instagram DM notifications and never asks for an Instagram username or password.
Which AI providers are supported?
The app is configured with whichever AI provider you choose inside the app, such as Groq, Gemini, OpenRouter and OpenAI-compatible endpoints.
Is InstaReply Bot free and open source?
Yes. The Android project is open source on GitHub and the APK is published through GitHub Releases at no cost.
How does the reply get sent?
When a rule matches, the app uses the notification reply action where available, with an accessibility-based fallback for sending when needed.
Can I control when replies are sent?
Yes. Rules support text matching, specific contacts, group behavior, ignored contacts, delays and daily send limits.

Trust and limits

Know what the app needs.

The page describes the mechanism rather than making broad security claims.

No Instagram password field

The workflow does not ask you to enter an Instagram username or password. It operates from Android notification access.

Notification Access is required

The automation depends on Android's Notification Listener permission for supported Instagram notifications.

Accessibility is a fallback

The project includes an accessibility-based fallback for sending when the notification reply action is not available.

AI providers are separate services

Generated replies are sent to whichever AI provider you configure. Review that provider's terms and data handling before use.
